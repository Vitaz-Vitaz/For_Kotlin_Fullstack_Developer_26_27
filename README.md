Library Management System

Консольное приложение на Kotlin для управления библиотекой

Возможности

1. Добавление и удаление книг
2. Поиск книг по названию, автору или ISBN
3. Регистрация пользователей: Student, Teacher, Guest
4. Выдача и возврат книг
5. Просмотр просроченных книг

Бизнес-правила

1. Student: до 3 книг, 14 дней
2. Teacher: до 10 книг, 30 дней
3. Guest: до 1 книги, 7 дней

Как запустить

1. Открыть проект в IntelliJ IDEA
2. Открыть src/Main.kt
3. Нажать Run
